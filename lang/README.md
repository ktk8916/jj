# 티~원줴줴이야 — 언어

이 폴더는 언어 그 자체입니다. 플레이그라운드(상위 폴더)와 무관하게 쓸 수 있습니다.

```
interpreter.js   인터프리터. 브라우저에서는 전역 T1JJYA, Node에서는 require
예제/            예제 프로그램 (기초 / 중급 / 상급)
test/            회귀 테스트: node lang/test/run-examples.js
```

Node에서 바로 쓰기:

```js
const T1JJYA = require('./interpreter.js');
const r = T1JJYA.run('티~원\n예? 마렵네...\n지~랄 예?\n줴줴이야');
console.log(r.ok, r.out);   // true '3\n'
```

`run(src, opts)`의 `opts.name`은 이 파일의 이름(확장자 없이), `opts.resolve(파일명)`은 다른 파일의 소스를 돌려주는 함수입니다. 결과는 `{ ok, out, mem, steps }` 또는 `{ ok: false, error, line, ... }`입니다.

## 문법

한 줄에 한 문장이고, 모든 변수는 0에서 시작합니다.

| 예약어 | 역할 | 쓰는 법 |
|---|---|---|
| `티~원` / `줴줴이야` | 블록 열기 / 닫기 | 혼자 한 줄. 프로그램 전체도 감쌈 |
| `예?`, `예??`, … | 변수 | 물음표 개수가 변수 번호 |
| `마렵네` | 더하기 | `예? 마렵네...` (점 개수만큼, 최대 3, 없으면 1) |
| `어흐어흐` | 빼기 | `예? 어흐어흐..` |
| `엄` | if | `엄 예?` (0이 아니면 참) |
| `아뇨아뇨아뇨` | else | `아뇨아뇨아뇨 엄 예??`는 else if |
| `앙기모링` | while | `앙기모링 예?` |
| `지~랄` | 출력 | `지~랄 예?` (숫자로 출력) |
| `랄로톤으로` | 함수 정의 | `랄로톤으로 곱 예? 예??` |
| `요이~` | 반환 | `예??? 요이~` |
| (함수 이름) | 호출 | `곱 예? 예??` / `예??? 곱 예? 예??` |
| `넌나가라` | 내보내기 | `넌나가라 곱` (다른 파일에 함수 공개) |
| `파일명.함수` | 다른 파일 함수 호출 | `예??? 수학.곱 예? 예??` |
| `#` | 주석 | 줄 끝까지 무시 |

- `엄`, `아뇨아뇨아뇨`, `앙기모링`, `랄로톤으로` 다음 줄에는 `티~원` 블록이 옵니다.
- 함수 이름은 한글이고, 프로그램 맨 바깥에서만 정의합니다. 위아래 어디서든 부를 수 있고 재귀도 됩니다.
- 함수 안의 변수는 바깥과 별개이며, 인자는 값이 복사돼 들어갑니다. `요이~` 없이 끝나면 0을 돌려줍니다.
- 파일 이름은 한글만 쓸 수 있고, 폴더가 달라도 겹칠 수 없습니다.
- `넌나가라`로 내보낸 함수만 다른 파일에서 부를 수 있습니다. 불려간 파일은 함수만 빌려주고 본문은 실행되지 않습니다.
- 1557, 1601, 88848, 8884844는 출력할 수 없습니다.

```
티~원
예? 마렵네...
앙기모링 예?
티~원
지~랄 예?
예? 어흐어흐
줴줴이야
줴줴이야
```

출력: `3` `2` `1`

## 예제

**기초** (`예제/기초/`)

기본 기능을 하나씩 설명합니다. 순서대로 보면 됩니다.

| 파일 | 내용 |
|---|---|
| `시작하기.jj` | 프로그램 틀(`티~원` … `줴줴이야`), 변수, `마렵네`, `지~랄` 출력 |
| `변수.jj` | 물음표 개수가 변수 번호, 모두 0에서 시작, 변수끼리는 독립 |
| `연산.jj` | `마렵네`와 `어흐어흐`, 점으로 1~3씩, 음수, 큰 값 만들기 |
| `조건문.jj` | `엄`(if), `아뇨아뇨아뇨 엄`(else if), `아뇨아뇨아뇨`(else), 0이 아니면 참 |
| `반복문.jj` | `앙기모링`(while), 카운트다운, 반복 횟수 세기 |
| `함수.jj` | `랄로톤으로`로 정의, `요이~`로 반환, 결과 받기/안 받기, 인자는 값 복사 |

**중급** (`예제/중급/`)

| 파일 | 내용 |
|---|---|
| `홀짝.jj` | 1부터 6까지 홀짝 판별 (조건문과 반복문 조합) |
| `구구단.jj` | 2단부터 9단까지 (함수, 반환값) |
| `피보나치.jj` | 피보나치 수열 10개 |
| `팩토리얼.jj` | 1!부터 6!까지 (재귀) |
| `수학.jj` | 더하기, 곱, 복사를 내보내는 공용 함수 파일 |
| `제곱.jj` | 수학.곱을 가져다 1부터 5까지 제곱 (다른 파일 쓰기) |

**상급** (`예제/상급/`)

| 파일 | 내용 |
|---|---|
| `하노이.jj` | 원판 3개짜리 하노이의 탑. 기둥 세 개를 스택으로 표현해 옮겨지는 과정을 출력 |
| `스택.jj` | 숫자 하나를 스택으로 쓰는 라이브러리 (값은 1~9) |
| `산수.jj` | 빼기, 나누기, 나머지, 크기 비교를 +1과 -1로 만든 라이브러리 |

하노이는 스택을, 스택은 산수를 가져다 쓰는 3단 구조입니다. 출력은 세 줄이 한 장면(1번, 2번, 3번 기둥)이고, `321`은 큰 원판부터 쌓인 탑, `0`은 빈 기둥입니다.
