# 티~원줴줴이야

한글 말투만으로 프로그램을 짜는 아주 작은 프로그래밍 언어와, 브라우저에서 바로 써 볼 수 있는 플레이그라운드입니다.

요즘 유행하는 **"한남말투"** 와 난해한 프로그래밍 언어 **"엄랭"** 에서 영감을 받아 만들었습니다. 예약어는 전부 특유의 말투이고, 숫자와 기호는 한 글자도 쓸 수 없습니다. 값은 오직 하나씩 더하고 빼서 만들고, 그걸로 조건문·반복문·함수·재귀·다른 파일 불러오기까지 전부 됩니다.

**바로 써 보기 → https://ktk8916.github.io/jj/**

```
티~원
예? 마렵네...
앙기모링 예?
티~원
지~랄 예?
예? 어흐어흐
줴줴이야
줴줴이야
```

출력: `3` `2` `1`

## 언어

프로그램은 `티~원`으로 열고 `줴줴이야`로 닫습니다. 한 줄에 한 문장이고, 모든 변수는 0에서 시작합니다.

| 예약어 | 역할 | 쓰는 법 |
|---|---|---|
| `티~원` / `줴줴이야` | 블록 열기 / 닫기 | 혼자 한 줄. 프로그램 전체도 감쌈 |
| `예?`, `예??`, … | 변수 | 물음표 개수가 변수 번호 |
| `마렵네` | 더하기 | `예? 마렵네...` (점 개수만큼, 최대 3, 없으면 1) |
| `어흐어흐` | 빼기 | `예? 어흐어흐..` |
| `엄` | if | `엄 예?` (0이 아니면 참) |
| `아뇨아뇨아뇨` | else | `아뇨아뇨아뇨 엄 예??`는 else if |
| `앙기모링` | while | `앙기모링 예?` |
| `지~랄` | 출력 | `지~랄 예?` (숫자로 출력) |
| `랄로톤으로` | 함수 정의 | `랄로톤으로 곱 예? 예??` |
| `요이~` | 반환 | `예??? 요이~` |
| (함수 이름) | 호출 | `곱 예? 예??` / `예??? 곱 예? 예??` |
| `넌나가라` | 내보내기 | `넌나가라 곱` (다른 파일에 함수 공개) |
| `파일명.함수` | 다른 파일 함수 호출 | `예??? 수학.곱 예? 예??` |
| `#` | 주석 | 줄 끝까지 무시 |

- `엄`, `아뇨아뇨아뇨`, `앙기모링`, `랄로톤으로` 다음 줄에는 `티~원` 블록이 옵니다.
- 함수 이름은 한글이고 프로그램 맨 바깥에서만 정의합니다. 어디서든 부를 수 있고 재귀도 됩니다. 함수 안의 변수는 바깥과 별개이며 인자는 값이 복사돼 들어갑니다.
- 파일 이름은 한글만 쓸 수 있고, `넌나가라`로 내보낸 함수만 다른 파일에서 `파일명.함수`로 부를 수 있습니다.
- 1557, 1601, 88848, 8884844는 출력할 수 없습니다.

자세한 규칙, 예제 설명, Node에서 인터프리터를 쓰는 법은 [lang/README.md](lang/README.md)에 있습니다. 예제는 기초(시작하기 → 변수 → 연산 → 조건문 → 반복문 → 함수), 중급(홀짝, 구구단, 피보나치, 팩토리얼, 수학, 제곱), 상급(하노이의 탑, 스택, 산수) 순서로 있습니다.

## 플레이그라운드

https://ktk8916.github.io/jj/ — VS Code 느낌의 편집기입니다. 서버 없이 정적 파일만으로 동작하고, 내려받아 `index.html`을 열어도 똑같이 됩니다.

**화면**

- 왼쪽 활동 막대: **문법**, **예제**, **탐색기** 패널과 아래쪽의 **설정**. 세 패널은 기본으로 모두 펼쳐져 있고, 각 아이콘이나 × 버튼으로 따로 접고 펼 수 있습니다.
- 가운데: 탭과 편집기. 구문 강조, 줄 번호, 오류 난 줄 표시.
- 오른쪽: 터미널 패널. **출력**과 **변수**(실행이 끝난 뒤 본문 변수 값) 탭.

**예제 워크스페이스**

- 예제 15개가 기초·중급·상급 폴더로 들어 있습니다. 열어서 실행하고 읽어 볼 수 있지만 원본은 바뀌지 않습니다(읽기 전용, 삭제 불가).
- 고쳐 보고 싶으면 편집기 위의 **내 파일로 복사**를 누릅니다.

**탐색기 (내 워크스페이스)**

- **새 파일**로 파일을 만듭니다. 이름은 한글만, `폴더/이름`으로 폴더에 넣을 수 있고, 예제와 이름이 겹칠 수 없습니다.
- 파일은 브라우저(localStorage)에 저장돼 다음에 와도 그대로 있습니다. 처음 방문하면 비어 있습니다.

**실행과 읽기**

- **실행**(Ctrl+Enter / F5): 결과가 출력 패널에 나오고, 오류가 나면 줄 번호와 이유를 알려 주며 그 줄을 빨갛게 표시합니다.
- **읽기**: 코드를 한 줄씩 소리 내어 읽습니다. 물결표(`~`)는 소리 내지 않아 `티~원`은 "티원"으로 읽습니다.
- **읽으면서 실행**: 실제 실행 순서대로 줄을 짚어 가며 읽고, 출력이 나오는 순간 출력 패널에 찍힙니다.
- **설정**(톱니): 목소리, 속도(기본 1.5), 높낮이, 크기. "들어보기"로 바로 확인할 수 있고 설정은 저장됩니다.

**공유하기**

- 파일 경로 줄 오른쪽의 **공유하기**를 누르면 코드가 압축돼 URL의 `#` 뒤에 담기고 링크가 복사됩니다. 서버 없이 링크 하나로 코드가 전달되며, 그 파일이 부르는 내 파일들도 함께 담깁니다.
- 링크를 열면 내 파일로 복구해 편집기에 엽니다. 같은 이름이 이미 있으면 내용이 같을 때는 그대로 쓰고, 다를 때는 `이름공유.jj`로 저장합니다.

**단축키**

| 키 | 동작 |
|---|---|
| Ctrl+Enter, F5 | 실행 |
| Ctrl+J | 터미널 패널 열기/닫기 |
| Ctrl+B | 문법 패널 열기/닫기 |
| Ctrl+S | 저장 (자동 저장되지만 확인용) |
| Esc | 읽기 중지 |
| Tab | 공백 두 칸 |

## 프로젝트 구조

```
index.html, style.css   플레이그라운드 화면과 스타일
src/                    플레이그라운드 모듈 (dom, store, editor, layout, runner, speech, explorer, share, app)
src/examples.js         lang/예제/*.jj를 묶은 자동 생성 파일 (npm run build)
lang/                   언어: interpreter.js, 문법 문서, 예제, 테스트 (플레이그라운드 없이도 씀)
scripts/                예제 번들 빌드 스크립트
assets/                 아이콘
```

외부 라이브러리는 쓰지 않습니다(글꼴만 Google Fonts). `file://`에서도 열리도록 ES 모듈 대신 각 파일이 전역 `JJ`에 기능을 등록하며, `index.html`의 스크립트 순서가 곧 의존 순서입니다.

## 개발

```bash
npm run build   # lang/예제/ → src/examples.js (예제를 고치거나 추가했을 때)
npm test        # 빌드 + 예제 골든 출력 비교 + 오류 메시지·구문 강조 검사
```

새 예제는 `lang/예제/<단계>/<이름>.jj`로 두고 `scripts/build-examples.js`의 `ORDER`에 넣으면 탐색기에 그 순서로 보입니다. 예제 출력이 의도적으로 바뀌었을 때만 `npm run test:update`로 기대 출력을 갱신합니다.

**배포**: GitHub Pages가 `main` 브랜치의 루트를 그대로 서빙합니다. 빌드 단계가 없으므로 `src/examples.js`는 만든 뒤 반드시 함께 커밋합니다.
