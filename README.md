# 티~원줴줴이야

한글 예약어로 된 작은 프로그래밍 언어와, 브라우저에서 바로 써 볼 수 있는 플레이그라운드입니다.

- **언어** — [`lang/`](lang/README.md): 인터프리터, 문법 설명, 예제, 테스트. 플레이그라운드 없이 Node에서도 씁니다.
- **플레이그라운드** — 나머지 전부. VS Code 느낌의 편집기로, 정적 파일만으로 동작합니다.

```
티~원
예? 마렵네...
앙기모링 예?
티~원
지~랄 예?
예? 어흐어흐
줴줴이야
줴줴이야
```

출력: `3` `2` `1` — 문법 전체는 [lang/README.md](lang/README.md)에 있습니다.

## 플레이그라운드

서버 없이 `index.html`을 브라우저로 열면 되고, GitHub Pages에 그대로 올릴 수 있습니다.

```
index.html              화면 구조
style.css               스타일
src/dom.js              DOM 도우미, 대화상자 (prompt/confirm 대신 <dialog>)
src/store.js            상태(localStorage) 읽기·저장·정리, 파일 조회
src/editor.js           편집기 렌더링, 구문 강조, 커서·줄 표시
src/layout.js           왼쪽 패널(문법/예제/탐색기)과 터미널 패널
src/runner.js           실행과 결과 표시
src/speech.js           읽기, 읽으면서 실행, 음성 설정
src/explorer.js         탐색기, 탭, 파일 만들기·삭제·복사
src/share.js            링크 공유와 복구
src/app.js              단축키, 온보딩, 초기화
src/examples.js         lang/예제/*.jj를 묶은 자동 생성 파일 (직접 고치지 않되, 커밋은 해야 함)
assets/                 아이콘
scripts/build-examples.js   lang/예제/ → src/examples.js
.nojekyll               GitHub Pages가 Jekyll 처리를 건너뛰게 함
```

외부 라이브러리는 쓰지 않습니다(글꼴만 Google Fonts). `file://`에서도 열리도록 ES 모듈 대신 각 파일이 전역 `JJ`에 기능을 등록하며, `index.html`의 스크립트 순서가 곧 의존 순서입니다.

처음 방문하면 문법·예제·탐색기를 소개하는 안내창이 뜨고, 활동 막대 맨 아래 도움말 버튼으로 다시 볼 수 있습니다. 처음에는 내 파일도 열린 탭도 없이 시작합니다.

왼쪽 활동 막대에는 **문법 · 예제 · 탐색기** 세 패널이 있습니다. 각 아이콘과 패널의 × 버튼은 자기 패널만 열고 닫으며, 여러 패널을 나란히 열어 둘 수 있습니다(기본은 문법과 예제). Ctrl+B는 문법 패널을 토글합니다. 화면이 좁으면 패널이 편집기 위에 겹쳐 뜨므로 한 번에 하나만 보이고, 파일을 열면 접힙니다.

- **문법**: 언어 설명.
- **예제**: 항상 원본 그대로인 예제 파일. 열어서 실행·읽기는 되지만 지우거나 고칠 수 없고, 고쳐 보려면 편집기 위의 "내 파일로 복사"를 누릅니다.
- **탐색기**: 내가 만든 파일. 브라우저(localStorage)에 저장됩니다. 파일 이름은 예제와도 겹칠 수 없습니다.

그 밖에 탭, 구문 강조, 실행(Ctrl+Enter / F5), 출력·변수 패널(Ctrl+J), 코드 읽어 주기와 한 줄씩 읽으면서 실행이 있습니다.

**음성**: 읽을 때 물결표(`~`)는 소리 내지 않아 `티~원`은 "티원"으로 읽습니다. 활동 막대 아래 톱니(설정)에서 목소리·속도(기본 1.5)·높낮이·크기를 바꿀 수 있고 설정은 브라우저에 저장됩니다.

**공유하기**: 파일 경로 줄 오른쪽의 "공유하기"를 누르면 열려 있는 파일이 URL의 `#` 뒤에 압축돼 담기고 클립보드에 복사됩니다. 서버 없이 링크만으로 코드가 전달되며, 그 파일이 부르는 내 파일들도 함께 담깁니다(예제는 받는 쪽에도 있으므로 제외). 링크를 열면 내 파일로 복구해 편집기에 엽니다. 같은 이름의 파일이 이미 있으면 내용이 같을 때는 그대로 쓰고, 다를 때는 `이름공유.jj`로 저장합니다.

**GitHub Pages 배포**: 저장소 Settings → Pages → Source를 `Deploy from a branch`, 브랜치 `main`, 폴더 `/ (root)`로 두면 됩니다. 빌드 단계가 없으므로 `src/examples.js`는 `npm run build`로 만든 뒤 반드시 함께 커밋합니다. 경로가 전부 상대 경로라서 `https://<계정>.github.io/<저장소>/` 하위에서도 동작합니다.

## 개발

예제를 고치거나 추가했으면 (새 예제는 `lang/예제/<단계>/<이름>.jj`로 두고 `scripts/build-examples.js`의 `ORDER`에 넣으면 탐색기에 그 순서로 보입니다):

```bash
npm run build
```

인터프리터를 고쳤으면:

```bash
npm test
```

예제 출력이 의도적으로 바뀌었을 때만 `npm run test:update`로 기대 출력을 갱신합니다.
